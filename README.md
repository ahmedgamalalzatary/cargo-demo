# تجزئة (cargo demo)

Frontend-only demo of a shipping system: bulk purchases from suppliers are cut into client orders, and each order goes to a delivery man. The interface is Arabic and right-to-left. Data is generated on first load and stays in the browser's localStorage.

```
npm install
npm run dev
```

`npm run build` writes a static site to `dist/` that can be hosted from any folder.

Demo accounts are listed on the sign-in page. "Reset demo data" in the sidebar restores the original data.
